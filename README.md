# Longboard Runner MVP

Минимальный горизонтальный раннер на Phaser 3 без графических ассетов.
Вся графика создаётся кодом через Phaser Graphics.

## Запуск

Самый простой вариант в VS Code:

1. Открыть папку проекта.
2. Запустить через Live Server.
3. Открыть `index.html`.

Либо через любой локальный HTTP-сервер.

## Управление

- `Space`
- `↑`
- тап / клик по экрану

После столкновения:
- `Space` или тап — рестарт.

## Что есть в MVP

- бесконечное движение дороги;
- параллакс города и объектов вдоль дороги;
- игрок на лонгборде;
- прыжок;
- 3 типа препятствий;
- постепенное увеличение скорости;
- дистанция;
- game over и restart;
- адаптация canvas под размер окна;
- мобильное управление тапом;
- никаких PNG/JPG/SVG ассетов.

## Файлы

- `index.html` — страница и подключение Phaser.
- `game.js` — вся игровая логика.
